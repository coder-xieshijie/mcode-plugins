# 章鱼少女开机动画（mcode-octopus-boot）

MCode 的开机画面插件：启动时铺满主窗口播放章鱼少女启动动画，底部细进度条跟随 MCode 的启动进度，片尾溶解进 MCode 主界面。附 3 张章鱼少女壁纸，在插件设置区「用作壁纸」。

## 组装与安装

```sh
sh plugins/octopus-boot/build.sh        # 生成 plugins/octopus-boot/dist/mcode-octopus-boot
```

把生成的 `mcode-octopus-boot` 目录放进 MCode 数据目录的 `plugins/` 下，MCode 会自动扫描并启用。打开插件详情页的“插件设置”：

- 打开「用作开机画面」，下次启动 MCode 时生效；
- 在想用的壁纸上点「用作壁纸」，模糊、暗化、阅读面不透明度在同一处调。

需要支持插件外观（开机画面与插件壁纸）的 MCode 版本。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 播放声音 | 开 | 关闭后静音播放；不允许带声自动播放时自动退回静音 |
| 结束方式 | 片尾溶解进界面 | 视频最后一段边播边溶解；或“放完再淡出”：停在最后一帧，放完再溶解 |
| 溶解时长 | 800 毫秒 | 200–3000 |
| 点击画面跳过 | 开 | MCode 没准备好时会等它准备好再进入 |
| 显示启动进度条 | 开 | |

## 壁纸

| 壁纸 | 来源 | 默认模糊 / 暗化 / 阅读面不透明度 |
|---|---|---|
| 电路线稿 | 开机动画首帧 | 6 / 35 / 86 |
| 代码唤醒 | 开机动画第二个关键帧 | 8 / 40 / 88 |
| 睁眼微笑 | 开机动画尾帧 | 10 / 30 / 88 |

壁纸由 16:9 关键帧居中裁成 16:10（1920×1200 WebP），重新生成用 `sh plugins/octopus-boot/make-wallpapers.sh`。

## 行为说明

- 先显示首帧封面，视频开始播放后再切到视频，保证 3 秒内有画面。
- 开机画面层是透明的：页面把自己淡到透明再调用 `dismiss()`，画面直接溶解进已经渲染好的主界面。所以 `html`、`body` 不设背景色，深色底放在 `#stage` 上随页面一起淡出；给 body 设底色会被浏览器画到整个画布上，淡出时停在这层颜色再硬切。
- 点击跳过同样走溶解：MCode 准备好就立刻淡出，没准备好就等就绪后再淡出。
- 默认在视频最后一段（溶解时长那么长）边播边溶解；MCode 那时还没准备好，就停在最后一帧（笑容）等，准备好后再溶解。
- 视频 4 秒内没出画面或播放出错，就停在封面，MCode 准备好后直接溶解进入。
- 系统开启“减少动态效果”时不播视频，只显示笑容那一帧，准备好后直接进入。
- Esc 任何时候都能跳过；MCode 准备好 30 秒后页面还没结束，MCode 会自行进入。这两条由 MCode 保证。
- 直接用浏览器打开 `dist/mcode-octopus-boot/pages/boot/index.html` 可以预览：页面会模拟 5 秒的启动进度。
